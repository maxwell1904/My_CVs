\cvsection{Giới thiệu}
Có nền tảng JavaScript/Node.js, kinh nghiệm Frontend tại MobiFone và Automation QC (OJT) tại FPT Software. Từng tham gia phát triển giao diện React, tích hợp REST API, phân tích lỗi và kiểm tra bản sửa. Định hướng phát triển web với React và Node.js, kết hợp kinh nghiệm lập trình và kiểm thử.

\cvsection{Kỹ năng}
\textbf{Frontend:} JavaScript (ES6+), TypeScript, HTML/CSS, React.js; component, props/state, form và xử lý dữ liệu bất đồng bộ.\\[2pt]
\textbf{Backend \& API:} Node.js, Express.js; REST API, HTTP/JSON, input validation và error handling; NestJS trong dự án.\\[2pt]
\textbf{Database:} Có kinh nghiệm dùng MongoDB và PostgreSQL/Supabase trong các dự án.\\[2pt]
\textbf{Testing \& Debugging:} Playwright, DevTools, Postman; phân tích test fail, tái hiện bug và kiểm tra lại sau khi sửa.\\[2pt]
\textbf{Công cụ:} Git/GitHub, Unix CLI, Docker cơ bản (image, container); sử dụng AI hỗ trợ tìm hiểu kỹ thuật và phát triển, có kiểm tra kết quả.\\[2pt]
\textbf{Tiếng Anh:} Giao tiếp tự tin, trao đổi kỹ thuật và đọc hiểu tài liệu chuyên môn.
